Hermes Personal Tasks

Редакция от 9 ноября 2026 года.

1. Приложение и владелец

Hermes Personal Tasks — личное приложение владельца профиля Nataananda на GitHub для управления делами и покупками в Google Tasks через Telegram и Hermes Agent на личном сервере. Личное подключение Tasks ещё готовится; ниже описана предусмотренная схема обработки после его включения.

2. Доступ к Google Tasks

Приложение запрашивает разрешение https://www.googleapis.com/auth/tasks: чтение, создание, изменение и удаление задач аккаунта. Программа работает с выбранными списками «Дела» и «Покупки»; при настройке читает перечень списков, чтобы найти их. Само разрешение Google распространяется на все задачи аккаунта.

Обрабатываются названия и примечания задач, сроки, состояние выполнения, сведения о завершении, идентификаторы списков и задач, ссылки и технические версии записей. Эти данные нужны для исполнения поручений, поиска задач, показа списков, подготовки напоминаний и предотвращения повторных действий.

3. Как проходят данные

Сообщения и ответы проходят через Telegram. На сервере Hermes обрабатывает поручение, обращается к Google Tasks и отправляет результат в личный чат. Для связи с чатом используются идентификаторы пользователя, чата и сообщений Telegram.

В описываемой схеме для обработки обычных фраз используется модель OpenAI через подключение Hermes к OpenAI Codex. Это соответствует последней подтверждённой настройке личного Hermes от 8 ноября 2026 года. Текст запроса и необходимые результаты работы с задачами могут передаваться OpenAI как часть контекста разговора. Hermes выбирает контекст для каждого обращения, а не обязательно передаёт всю сохранённую историю.

На обработку у OpenAI распространяются условия и настройки выбранного подключения. Эта политика не обещает отсутствия хранения у поставщика модели или определённого срока удаления данных у него.

Google обрабатывает данные задач, Telegram — сообщения, поставщик сервера предоставляет инфраструктуру хранения и исполнения программы. Приложение предназначено для выполнения личных поручений, а не для продажи данных или рекламного профилирования.

4. Хранение и удаление

Основные записи задач хранятся в Google Tasks. Штатный механизм Hermes предусматривает сохранение истории разговоров на личном сервере, включая сообщения, обращения к инструментам и их результаты. Подготовленное дополнение сохраняет журнал операций с содержимым задач, данные дневных карточек и напоминаний, идентификаторы Telegram и состояния действий. Диагностические журналы также могут содержать сведения об обработке.

Если владелец включает рабочие файлы в резервное копирование, их копии сохраняются и там. Включение будущих данных Tasks в существующие резервные копии ещё не проверено.

После подключения файлы разрешения Google будут храниться на сервере отдельно от публичных страниц. Они позволяют программе обращаться к Google без повторного входа и не предназначены для публикации.

В подготовленном дополнении не установлен единый автоматический срок удаления всех локальных данных. Очисткой сервера и резервных копий управляет владелец. Сроки хранения у Google, Telegram и поставщика модели определяются их условиями и настройками.

Удаление задачи в Google Tasks не удаляет автоматически её прежние копии из сообщений Telegram, истории Hermes, журнала операций или резервных копий.

5. Управление доступом

Владелец может отозвать разрешение приложения в настройках подключений Google-аккаунта. После вступления отзыва в силу приложение не сможет получать новые разрешённые этим подключением данные или менять задачи через него. Уже сохранённые данные требуют отдельного удаления в соответствующих сервисах и на сервере.

6. Эти публичные страницы

Страницы содержат только описание приложения и эту политику. Они не подключаются к Google Tasks, не принимают сообщения и не отображают личные задачи. В их коде нет форм, сценариев аналитики, рекламных элементов или собственных механизмов отслеживания.

При размещении на GitHub Pages GitHub записывает IP-адреса посетителей для обеспечения безопасности, как указано в документации GitHub Pages. Обработка этих сведений регулируется политикой конфиденциальности GitHub.

7. Контакт и изменения

Профиль владельца для связи по вопросам приложения и данных: https://github.com/Nataananda. Это ссылка на профиль GitHub, а не форма отправки личного сообщения. Адрес почты и Telegram на этих страницах не публикуются.

При изменении состава доступа, способов обработки или хранения данных владелец обновляет эту политику и дату её редакции.
